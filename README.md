## ⚙️ How My Automations Work

```text
 Trigger  ─►  Google Sheets  ─►  Transform  ─►  HTTP Request / API  ─►  Result
   │                                 ▲
   └──────────────  Loop  ───────────┘
```

Typical workflows I build: collecting data, cleaning and transforming it,
looping over records, calling external APIs and AI services, and writing the
results back to Google Sheets — all running automatically.
